# Quelltext des Design-Artefakts

Spiegel der Artboards aus dem Design-Artefakt (siehe [../design-artifact.md](../design-artifact.md)).
Die `*.dc.html`-Dateien sind Design-Komponenten des Artefakt-Editors; sie benötigen dessen
Laufzeit (`support.js`) und werden weder gebaut noch mit der Website ausgeliefert. Alle Inhalte sind
frei erfundene Beispieldaten.
